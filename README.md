# Modern Creative Landing Page

A stylish, responsive landing page template featuring a clean UI, creative typography, and a modern layout. This project focuses on high-quality visual presentation and smooth user experience.

## 🚀 Features

- **Hero Section:** A bold introductory section with a large background image and stylized typography.
- **Custom Typography:** Integration of Google Fonts including **Pacifico** for branding and **Raleway/Work Sans** for readability.
- **Responsive Design:** Fully adaptive layout using Media Queries to ensure a great look on mobile and desktop devices.
- **Social Integration:** A dedicated "Get in Touch" section with styled social media icons from Font Awesome.
- **Clean Navigation:** Minimalist header and footer navigation menus.
- **CSS Architecture:** Organized styles using a custom reset and a structured main stylesheet.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Custom styling featuring:
  - **Flexbox:** For alignment and complex layouts.
  - **Media Queries:** For mobile responsiveness.
  - **Transitions:** For interactive hover effects.
- **Google Fonts:** Custom web typography.
- **Font Awesome 7.0.1:** Modern vector icons for social media and UI elements.

## 📂 Project Structure

```text
├── css/
│   ├── reset.css       # Standard CSS reset for cross-browser consistency
│   └── style.css       # Main stylesheet with custom layouts and components
├── image/              # Folder for background images and logos
└── index.html          # Main entry point of the website
```
